# Tesis: agente conversacional de reabastecimiento

Diseño e implementación de un agente conversacional para la recomendación de reabastecimiento en pequeñas empresas comerciales.

Ver [PLAN.md](PLAN.md) para el detalle completo.

## Estructura

- `frontend/` — React + Vite (app móvil)
- `api/` — FastAPI (motor de pronóstico + agente)
- `supabase/` — migraciones y seed de PostgreSQL
